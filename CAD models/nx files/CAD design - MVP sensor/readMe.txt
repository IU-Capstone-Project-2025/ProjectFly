Here is name & description of parts of the floating mechanism, parts consisting of multiple parts are grouped together.
In the directory you find two assembly files and separate part files.
rodTankAssembly is the global assembly file containing all the parts.

Float: (consists of two parts to be assembled with snap joints, housing up to 4 magnets)
- part1name: float: first part of the float
- part2name: float - Copie: second part of the float


Bottom cap:
- part3name: bottomcap: serves to block float from escaping from the rod column

Sensor rod (shaft)
- part4name: rod2: main vertical column of the sensor to guide the float and serves as housing of IC with reed sensors (still low fidelity, no fixing of IC yet)


Assembling tool (consists of three parts to be glued together): serves to fix the bottom cap
- part5name: toolHandler: first part of assembling tool
- part6name: toolHandle2: second part of assembling tool
- part7name: tool: third part of assembling tool
